# External Infrastructure Register

> **Purpose:** the one date-stamped list of every outside host, service or network a shipped Star Station Furlong build can contact — by name, or as a class for the http(s) links a room record can carry — with the class each falls in: being removed, exempt, optional, and local or peer. **The principle it serves (Dorkmo, 2026‑10‑12):** the station relies on no central infrastructure such as websites. Rulings it inherits: the serverless-sources ruling of 2026‑10‑04 (the convenience lanes are off by default, [sovereignty.ts](../../prototypes/0.29.0-core-loop-demo/src/sovereignty.ts)) and [#231 D1](https://github.com/Bella-Addormentata/StarStationFurlong/issues/231) of 2026‑10‑11 (peer-protocol chain access, [sovereign plan §14](../../brainstorming/sovereign-treasury-serverless-plan.md)).
>
> **Owner:** whoever touches a row's code. **Rule:** a change that makes a build contact a new host, or changes a row's default, updates this file in the same PR and names the row in the PR description; a row that owes work points at its TODO item. **Re-verify** every row with the commands in §6 before each release and stamp the Checked column.

## 1. The classes

- **Being removed** — a dependency that breaks the principle. The row stays until no shipped code names the host, then moves to §7.
- **Exempt** — central infrastructure the project accepts, each with the condition that makes it acceptable (bootstrap only, build machine only, distribution only) and the sovereign upgrade that would retire it.
- **Optional** — off by default. The row says who turns it on (a build flag, an operator's environment variable, a room owner, a viewer's consent) and what the player sees. A peer's record can never turn a lane on; where a lane, once on, also follows hosts a peer names, the row says so (operator relays).
- **Local or peer** — not central at all: the LAN, the player's own router, loopback, and the other players' own nodes reached over the mesh, on the LAN or across the Internet. Listed so nobody mistakes them for third parties.
