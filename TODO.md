- [ ] **🛑 The node refuses a room update that every page refuses, on the raw bytes, before it decodes it — core guard LANDED in [#350](https://github.com/Bella-Addormentata/StarStationFurlong/pull/350) ([#55]; found 2026‑11‑01, merged 2026‑11‑01)** — `ssf-p2p-node` links `yrs 0.27.2`, whose v1 decoder builds strings with `from_utf8_unchecked`: one 13‑byte ysync frame holding a non‑UTF‑8 string **segfaults the node** (reproduced locally; `010101000401017403ff626300`), deep `Any` nesting overflows the worker stack (~5000), and a huge declared length OOM‑aborts. The iroh lane **relays a frame to every mesh peer and local tab before it ever decodes it** (`main.rs` ~3606/3621/3780), so any page or peer can take the owner's node — and its neighbours — down with one frame. Bumping to `yrs 0.28.0` (which validates UTF‑8) is **rejected**: it folds JS bigints (`Any` tag 122) into `Number::Int` and re‑encodes small ones as plain numbers, so the node would serve `10` where peers hold `10n` and `house_bytes` parity breaks. Fix instead: a `pages_refuse(&[u8])` walker over raw v1 bytes that mirrors lib0's `readUpdate`/`readAny` and refuses exactly where every page's lib0 throws (non‑UTF‑8 anywhere, the lib0 varint MAX_SAFE cap, length‑vs‑remaining, a depth cap below the crash depth, ContentJSON, type refs ∉ {0,1,2,3,4,6}, XmlHook, ContentDoc non‑object opts, a content ref with no reader), run at the WT lane, the iroh lane **before** relay/dedup/retain, the persisted‑load path, and in `handle_ysync_message` — never calling `Update::decode_v1` itself. It must never refuse an update a page accepts (that diverges the docs the same way). Design: project Library `ssf-p2p/ingest-parity-design.md`. **Follow‑up (R2):** the `__proto__` + typed‑array‑getter trap keys (the oversized case Copilot flagged on [#348](https://github.com/Bella-Addormentata/StarStationFurlong/pull/348)'s `house_bytes.rs`), an exact V8 `[[Set]]` model, ship in a second PR with the house's own oversized‑typed‑getter read gap. **Status 2026‑11‑01:** the core guard landed in [#350](https://github.com/Bella-Addormentata/StarStationFurlong/pull/350) (Copilot's 3 HIGH [raw GC/Skip dispatch, parentInfo u32‑wrap, signed‑varint shift‑69 + `i64::MIN` negation] + 2 MEDIUM fixed, each with a regression test built from a page‑oracle divergence fixture; `pages_refuse` runs at the WT lane, the iroh lane before relay/dedup/retain, the persisted‑load path and `handle_ysync_message`).
